# RahmiCourse

Website pembelajaran yang menyediakan materi, latihan, dan sumber belajar untuk mendukung proses pembelajaran siswa dan pengembangan kompetensi guru.

## 🌐 Website
https://rahmicourse.github.io/

## 📚 Tentang Proyek
RahmiCourse dikembangkan sebagai platform pembelajaran digital yang menyediakan:

- Materi pembelajaran
- Modul dan bahan ajar
- Latihan dan evaluasi
- Sumber belajar berbasis teknologi
- Konten pendukung literasi digital dan AI dalam pendidikan

## 🎯 Tujuan
Membantu peserta didik dan pendidik memperoleh akses pembelajaran yang mudah, menarik, dan fleksibel melalui teknologi web.

## 🛠️ Teknologi yang Digunakan
- HTML
- CSS
- JavaScript
- GitHub Pages

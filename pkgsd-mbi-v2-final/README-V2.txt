PKGSD-MBI V2 — PETUNJUK

1. Folder ini adalah salinan baru, tidak mengubah versi lama.
2. Unggah folder pkgsd-mbi-v2 ke root repository rahmicourse.github.io.
3. Buka https://rahmicourse.github.io/pkgsd-mbi-v2/ setelah GitHub Pages diperbarui.
4. Edit link di media-config.js saja. Kelompok: agenda, analisis, modelling, microteaching, audio, games, extras.
5. Contoh untuk menambah game di Pertemuan 2: pada entri "2", tambahkan "games": [["Game 1", "https://alamat-game"]].
6. Video/PDF/Game hanya dapat ditampilkan dalam website jika penyedia mengizinkan iframe/embedding dan file memiliki izin akses. Link folder Drive dan DOCX mungkin tidak dapat dipratinjau.
7. Link yang sudah diketahui dimasukkan untuk Pertemuan 2,6,7,8,9,10; pertemuan lain dibiarkan kosong agar tidak mengarang bahan.
8. Audio atau game belum diisi karena belum ada URL yang diberikan.
9. Simpan salinan ZIP lama sebelum menerapkan perubahan.
